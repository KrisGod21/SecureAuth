Meet HC-ADS v2

A research composition of existing cryptographic primitives. The innovation is the orchestration: separate transport and storage keys, context-bound synthetic IVs, a hybrid cipher cascade and authentication before decryption.

What SHA-256 does

It provides a visible fingerprint of the encoded ciphertext. The server decrypts, re-encrypts and compares the digest. A digest alone does not authenticate a message; the independent keyed MAC does.

Two keys with two jobs

A temporary ECDH-derived key protects this browser's messages. A separate server-only master key protects records at rest. Neither key is stored in browser storage or source code.

Freshness for every action

Each request uses a random challenge that expires in 60 seconds. Field labels bind the action, challenge and field name. The server consumes each challenge once.

Honest security boundaries

This is an educational algorithm, without a formal security proof. Triple DES is retired for new NIST encryption use. Deterministic student IDs reveal equality; passwords are stored as salted scrypt hashes. Usernames are readable. Deployments need HTTPS and a vetted modern cipher.
